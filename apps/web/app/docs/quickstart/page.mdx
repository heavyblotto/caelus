# Quickstart

Caelus calculates astrological charts from a Universal Time (UT) timestamp
and geographic coordinates. Because the core package performs no disk or network
I/O, identical code runs in browsers, edge workers, and Node.js.

## Install

<CodeBlock lang="bash" code="npm install caelus" />

## Compute a chart

Pass the ephemeris dataset explicitly when constructing `Engine`. The bundled
embedded dataset works out of the box without loading external files:

<CodeBlock
  run
  lang="typescript"
  label="chart.ts"
  code={`import { Engine, fmtLon } from "caelus";
import { embeddedData } from "caelus/data-embedded";

const engine = new Engine(embeddedData);

// year, month, day, hour, minute, second (UT), lat, lon (east+), house system
const chart = engine.chart(1990, 6, 10, 14, 30, 0, 27.95, -82.46, "placidus");

fmtLon(chart.bodies.sun.lon);   // "19°27' Gemini"
chart.bodies.saturn.retrograde; // true
chart.angles.asc;               // ascendant longitude, degrees`}
/>

Click **Run** to execute this snippet directly in your browser against the
embedded dataset and inspect the final expression. Data downloads lazily on the
first run, and computation happens locally without calling a server.

<Note>
  <code>engine.chart()</code> expects timestamps in Universal Time (UT). A
  four-hour timezone offset shifts the Ascendant by roughly 60°. Use{" "}
  <code>caelus-birth</code> to convert local civil time from coordinates; see{" "}
  <a href="/docs/charts">Computing Charts</a>.
</Note>

## Returned chart structure

Each returned chart object includes every calculated body (longitude, speed,
retrograde flag, zodiac sign, and equatorial coordinates), the chart angles,
all twelve house cusps, and active aspects. See{" "}
<a href="/docs/charts">Computing Charts</a> for the complete field layout.

<Note>
  If you want a ready-made application instead of building from primitives,
  start from the{" "}
  <a href="https://github.com/heavyblotto/caelus-starter">caelus-starter</a>{" "}
  Next.js template. It includes a birth-data form, offline timezone lookup via{" "}
  <code>caelus-birth</code>, a responsive chart wheel, and an optional
  interpretation route.
</Note>
