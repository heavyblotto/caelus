# Recipes

## Query time intervals with `when()`

Use `when()` to find every interval in a date range during which a compound
condition holds true. Combine individual sky predicates using `allOf`, `anyOf`,
and `notOf`:

<CodeBlock
  lang="typescript"
  label="when.ts"
  code={`import { when, allOf, aspect, inSign, notRetrograde, julianDay } from "caelus";

const start = julianDay(2026, 1, 1);
const end = julianDay(2028, 1, 1);

const intervals = when(
  engine,
  allOf(
    aspect("saturn", "square", 95.4), // within orb of an exact square to a longitude
    notRetrograde("mercury"),
    inSign("venus", "Taurus"),
  ),
  start, end,
);`}
/>

## Search sky events

With the Node data loader (or the embedded tier for lunar/solar basics), search
horizon events, lunar phases, planetary stations, and zodiac crossings:

<CodeBlock
  lang="typescript"
  label="events.ts"
  code={`import { lunarPhases, stations, julianDay } from "caelus";

const jd = julianDay(2026, 1, 1);
lunarPhases(engine, jd, jd + 90);   // [[jd, "full"], ...]
stations(engine, "mercury", jd, jd + 365);`}
/>

## Score similar sky configurations

Convert any timestamp's planetary state into a feature vector with
`chartFeatures`, then rank dates in another interval by angular similarity
using `searchConfigurations`:

<CodeBlock
  lang="typescript"
  label="match.ts"
  code={`import { chartFeatures, searchConfigurations, julianDay } from "caelus";

// the feature vector of a target moment (say, a natal chart)
const target = chartFeatures(engine, julianDay(1990, 6, 14, 12, 0));

// rank the next year by resemblance to that configuration, best first
const matches = searchConfigurations(engine, target, {
  start: julianDay(2026, 1, 1),
  end: julianDay(2027, 1, 1),
  step: 1,        // days
  limit: 5,
});`}
/>

## Synthesize planetary positions from constraints

`compileForm` solves the inverse problem: pass geometric constraints on aspects,
signs, and degrees and get synthetic planetary longitudes that minimize
constraint residual, flagging `impossible` when the best solution still violates
a requirement:

<CodeBlock
  lang="typescript"
  label="compile.ts"
  code={`import { compileForm } from "caelus";

const form = compileForm([
  { kind: "aspect", a: "sun", b: "moon", angle: 120 }, // a trine
  { kind: "sign", body: "mars", sign: 7 },             // Scorpio (0-indexed)
  { kind: "degree", body: "venus", degree: 15 },
]);

form.longitudes;  // { sun, moon, mars, venus }
form.residual;    // total weighted constraint loss, in degrees
form.impossible;  // true when the worst constraint cannot be met`}
/>

## Render a chart wheel

Pass any `Chart` object (or canonical JSON payload) to `ChartWheel` in
`caelus-wheel` to render an SSR-compatible SVG diagram:

<CodeBlock
  lang="tsx"
  label="Wheel.tsx"
  code={`import { ChartWheel } from "caelus-wheel";

<ChartWheel chart={chart} size={520} showAspects />;`}
/>

Try wheels interactively in the <a href="/playground">Playground</a> or browse
full signatures in the <a href="/docs/api">API Reference</a>.
