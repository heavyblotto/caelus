# Synthetic ephemeris

While `compileForm` solves planetary positions for a single static snapshot, the
synthetic ephemeris module lets you define moving imaginary bodies with custom
parameters so transits, returns, retrograde loops, and Sky View animations work
out of the box on fictional worlds.

Three motion modes offer increasing physical realism:

| Mode | Behavior |
|------|----------|
| `placement` | Fixed longitude matching `compileForm` |
| `periodic` | Uniform circular motion completing one orbit every `periodDays` |
| `kepler` | Constant orbital elements with true heliocentric coordinates |

## World frame vs. Earth sky

**World frame (`syntheticPositions` / `syntheticEphemeris`)**: evaluates bodies
inside their own standalone coordinate frame. Setting `observer` on the system
anchors the vantage point to a chosen body so outer objects display apparent
retrograde motion near opposition. Time is measured in abstract days relative to
each body's `periodDays` and `epoch`.

**Real Earth sky (`registerSyntheticSystem(engine, sys)`)**: mounts synthetic
bodies onto a live `Engine` via `registerSource` so `returns`, `transits`, and
`skyView` include them alongside real planets. In this mode, `epoch` uses a TT
Julian Day and the observer is Earth:

```ts
import { Engine, registerSyntheticSystem, julianDay, skyView } from "caelus";
import { embeddedData } from "caelus/data-embedded";

const engine = new Engine(embeddedData);
registerSyntheticSystem(engine, {
  id: "verdant-moon",
  bodies: [{
    id: "verdant", mode: "kepler",
    a: 3.2, e: 0.05, i: 2, node: 80, peri: 30, M0: 0,
    periodDays: 2100, epoch: julianDay(2000, 1, 1),
  }],
  render: { verdant: { sizeDeg: 0.4, magnitude: -1.2, color: "pale gold" } },
});

const jd = julianDay(2025, 6, 21, 12);
const frame = skyView(engine, jd, {
  observer: { lat: 40, lonEast: -75 },
  aim: { azimuth: "S", altitude: 45 },
  lens: "wide",
  image: { width: 1024, height: 683 },
}, { bodies: ["sun", "verdant"] });
// frame.bodies[].color, sizePx, and frame.prompt carry the authored appearance
```

## Validation

`validateSyntheticSystem` catches duplicate body IDs, non-positive orbital
periods, out-of-range eccentricities, and `observer` references missing from
the system. Invalid configurations return `impossible: true` alongside a
`problems` list instead of failing silently.

## MCP integration

`caelus-mcp` exposes `synthetic_validate`, `synthetic_positions`, and
`synthetic_sky_view`. See [MCP Setup](/docs/mcp) for configuration.
