# Hellenistic time-lords

Time-lord systems partition a life into consecutive periods ruled by specific
planets or zodiac signs. Caelus computes these classical Hellenistic and
Persian techniques using deterministic arithmetic on top of its validated
planetary positions, returning active lords, signs, and period boundary dates
with each underlying convention documented below.

All time-lord helpers expect a UT natal Julian Day. Convert local birth times
with `caelus-birth` first (see [Computing Charts](/docs/charts)):

```text
import { julianDay } from "caelus";
const natal = julianDay(1990, 6, 10, 14, 30);   // UT
```

## Lots (Arabic parts)

The seven Hermetic lots (Fortune, Spirit, Eros, Necessity, Courage, Victory,
and Nemesis) measure ecliptic arcs cast from the Ascendant, reversing direction
between day and night births. Fortune and Spirit mirror each other across the
Ascendant:

<CodeBlock
  lang="typescript"
  label="lots.ts"
  code={`import { Engine, lots } from "caelus";
import { embeddedData } from "caelus/data-embedded";
const engine = new Engine(embeddedData);

const l = lots(engine, natal, 27.95, -82.46);
l.fortune;   // longitude of the Lot of Fortune
l.spirit;    // Spirit is Fortune reflected across the Ascendant`}
/>

## Annual and monthly profections

In annual profections, the Ascendant advances one whole sign per completed year
of life, and the traditional ruler of the profected sign becomes lord of the
year. Monthly profections advance one additional sign per twelfth of a year:

<CodeBlock
  lang="typescript"
  label="profections.ts"
  code={`import { profectionAt } from "caelus";
const target = julianDay(2025, 6, 10);
const p = profectionAt(engine, natal, target, 27.95, -82.46);
p.age_years;        // completed years
p.annual.lord;      // lord of the year`}
/>

## Firdaria

The Persian firdaria divides a 75-year cycle into nine major periods (covering
the seven traditional planets plus the two lunar nodes), each planetary period
subdivided into seven equal sub-periods. Day charts begin the sequence with
the Sun, whereas night charts begin with the Moon:

<CodeBlock
  lang="typescript"
  label="firdaria.ts"
  code={`import { firdariaAt } from "caelus";
const f = firdariaAt(engine, natal, julianDay(2025, 6, 10), 27.95, -82.46);
f.major;   // the major-period lord active now
f.sub;     // the sub-period lord`}
/>

## Zodiacal releasing

Cast from a lot (commonly Spirit for vocation and action, or Fortune for body
and livelihood), zodiacal releasing unfolds sign by sign across four nested
sub-period levels. Caelus follows the standard Valens/Schmidt convention:
360-day prophetic years, 1/12 subdivisions per level, and *loosing of the bond*,
where a sub-period sequence returning to its opening sign jumps to the
opposite sign instead:

<CodeBlock
  lang="typescript"
  label="releasing.ts"
  code={`import { zrAt } from "caelus";
const z = zrAt(engine, natal, julianDay(2025, 6, 10), 27.95, -82.46, "spirit");
z.l1;   // the major (L1) sign active now
z.l2;   // the L2 sub-period sign`}
/>

## Primary directions

Primary directions project the diurnal rotation of the celestial sphere to
bring a significator into aspect with an angle or another planet, converting
equatorial arc of rotation into age via a time key (`"naibod"` at 0.9856° per
year or `"ptolemy"` at 1° per year). Caelus computes directions to the four
angles alongside Placidus semi-arc mundane directions between planets:

<CodeBlock
  lang="typescript"
  label="directions.ts"
  code={`import { primaryDirections, mundaneDirections } from "caelus";
// to the angles, within 90 years
primaryDirections(engine, natal, 27.95, -82.46);
// planet-to-planet (mundane) directions
mundaneDirections(engine, natal, 27.95, -82.46);`}
/>
