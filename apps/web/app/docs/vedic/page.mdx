# Vedic and Jyotish

Caelus includes a Jyotish module built directly on its validated sidereal
longitudes, covering nakshatras, nakshatra-based dashas, divisional charts
(vargas), and classical yogas.

Where classical Jyotish sources define multiple calculation variants, Caelus
selects a documented standard (such as Brihat Parashara Hora Shastra or P.V.R.
Narasimha Rao's JHora conventions) and verifies it in the `validate_jyotish`
test suite (see [Methods](/methods)). Functions default to the Lahiri ayanamsa
and accept any supported sidereal zodiac.

```text
import { julianDay } from "caelus";
const natal = julianDay(1990, 6, 10, 14, 30);   // UT
```

## Nakshatras

Divide the sidereal zodiac into the 27 lunar mansions of 13°20′ each, returning
the nakshatra name, quarter (`pada` 1–4), and dasha ruler:

<CodeBlock
  lang="typescript"
  label="nakshatra.ts"
  code={`import { Engine, nakshatraAt } from "caelus";
import { embeddedData } from "caelus/data-embedded";
const engine = new Engine(embeddedData);

const n = nakshatraAt(engine, natal);   // the Moon, sidereal Lahiri
n.name;   // e.g. "Rohini"
n.pada;   // 1..4
n.lord;   // the dasha lord of the nakshatra`}
/>

## Dashas

Three nakshatra-based dasha systems start from the Moon's birth nakshatra,
scaling the opening period by the elapsed arc of that mansion and subdividing
into proportional sub-periods:

- **Vimshottari**: the standard 120-year cycle returning active mahadasha,
  antardasha, and pratyantardasha lords.
- **Yogini**: the 36-year cycle spanning eight yoginis.
- **Ashtottari**: the 108-year conditional dasha using JHora/PVR nakshatra
  assignments.

<CodeBlock
  lang="typescript"
  label="dasha.ts"
  code={`import { vimshottariAt, yoginiAt, ashtottariAt } from "caelus";
const target = julianDay(2025, 6, 10);
vimshottariAt(engine, natal, target);   // { maha, antar, pratyantar, ... }
yoginiAt(engine, natal, target);        // { maha, antar, ... }
ashtottariAt(engine, natal, target);    // { maha, antar, ... }`}
/>

## Vargas (divisional charts)

Compute Parashari divisional placements for D1 (rasi), D2 (hora), D3
(drekkana), D9 (navamsa), D10 (dasamsa), D12 (dwadasamsa), and D30
(trimsamsa), either for a single longitude (`varga`) or across every body in a
chart (`vargaChart`):

<CodeBlock
  lang="typescript"
  label="vargas.ts"
  code={`import { varga, vargaChart } from "caelus";
// the navamsa sign of a sidereal longitude
varga(45.0, 9).sign;            // e.g. "Capricorn"
// the full D9 chart of every body
vargaChart(engine, natal, 9);`}
/>

## Yogas

Evaluate classical rasi combinations: the five Pancha Mahapurusha yogas,
Gajakesari, Budha-Aditya, and Chandra-Mangala placement yogas; Kemadruma
(isolated Moon, with a configurable planet list); and house-lordship and graha
drishti combinations yielding raja yogas, dhana yogas, and chart yogakarakas:

<CodeBlock
  lang="typescript"
  label="yogas.ts"
  code={`import { yogasAt, rajaYogasAt, kemadrumaAt } from "caelus";
yogasAt(engine, natal, 27.95, -82.46);       // the placement yogas present
rajaYogasAt(engine, natal, 27.95, -82.46);   // { raja: [...], yogakarakas: [...] }
kemadrumaAt(engine, natal, 27.95, -82.46);   // { present, planets_checked }`}
/>
