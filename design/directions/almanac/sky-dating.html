Instrument 01

Sky dating

Sky dating takes a partial description of a sky and lists every date that fits it. Scholars date ancient horoscopes the same way: a text that names the sign of each planet can be matched against the computed sky for every day in the supported span.

PlaceholderdateSky() is not in caelus 0.25.0. The windows shown here came from a daily scan that called engine.position() for each body on 2,190,726 days, and they have not been checked against a published corpus. The controls on this page are not wired.

Saturn in , Jupiter in , Mars in , the Sun in , Venus in , Mercury in , and the Moon in , at . The zodiac is tropical and the search runs from 3000 BCE to 3000 CE. Any condition can be left open, and the lunar phase is optional.

Positions are for 12:00 UT on the first day of each window. Dates before 15 October 1582 are given in the Julian calendar. The placeholder scan samples each day at 12:00 UT, so a Moon that changes sign during a day can add or drop a day at the edge of a window.

4. Method

The search prunes intervals from the slowest body to the fastest. Saturn's sign windows are found first, each is intersected with Jupiter's, and so on down to the Moon, so the fast bodies are only evaluated inside the few windows the slow ones leave open.

The classical packs carry the Sun, the Moon, Mercury, Venus, Mars, Jupiter, and Saturn back to 3000 BCE. Uranus, Neptune, and Pluto have no classical pack, so they cannot constrain a date before 1000 CE.

Listing 1. The callProposed API
import { Engine } from "caelus";
import { loadNodeData } from "caelus/node";

// The classical packs reach back to 3000 BCE.
const engine = new Engine(
  loadNodeData("./data", "embedded", "full"),
);

const windows = engine.dateSky({
  from: -2998,
  to: 3000,
  zodiac: "tropical",
  bodies: {
    saturn: "Aries",
    jupiter: "Leo",
    mars: "Leo",
    sun: "Scorpio",
    venus: "Libra",
    mercury: "Scorpio",
    moon: "Sagittarius",
  },
});

console.log(windows.length); // 3
