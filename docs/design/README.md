# Design system documents

Unpacked from the maintainer's `design-system.zip` (2026-08-19). The
`.dc.html` files are self-contained design documents; `support.js` is
their shared viewer script. Open them in a browser.

- `Caelus Site - current.dc.html` — DS-01 audit of the developer
  site's existing `globals.css` (inconsistency inventory).
- `Caelus Design System.dc.html` — DS-01 proposal: token-level
  refactor for the developer site.
- `Encyclopedia - article directions.dc.html` — DS-02 exploration:
  three Encyclopedia article directions (Plate, Apparatus, Register).
- `Encyclopedia Design System - Plate.dc.html` — DS-02 foundations for
  the chosen Plate direction, including the parts inventory the widget
  plan's contracts table references (entry link, kind marks, note
  marker, infobox, plate, revision stamp, plate console).

Adoption is tracked in `docs/product/encyclopedia-widgets-plan.md`
(widget/design side) and `docs/product/corpus-build-plan.md` (corpus
side).
