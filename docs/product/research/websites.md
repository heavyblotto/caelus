# Competitive research: top astrology websites (2025–2026)

Agent-gathered web research, 2026-08-15. Combines Similarweb/Semrush data,
site pages surfaced via search, third-party reviews, and product knowledge of
these long-stable sites. Traffic approximate. Tools, product structure, and
design only; content excluded.

**Traffic landscape (monthly visits, order of magnitude):** horoscope.com
~12M; astro-seek.com ~10–12.6M; astro.com ~9–10M; astrology.com ~6M;
cafeastrology.com ~4.5–6M; astrotheme, astro-charts, prokerala, astrosage in
the ~1–10M band. Astro-seek skews ~67% female, 25–34.

---

## 1. astro.com (Astrodienst) — reference-grade incumbent

**Positioning:** Swiss, online since 1996, the de-facto professional
standard; Swiss Ephemeris licensor to most of the industry. ~60% direct
traffic — uniquely loyal base.

**Model:** essentially all calculation free (ad-supported). Registration
(free) stores up to 100 birth datasets. Paid: AstroShop computed reports (Liz
Greene, Robert Hand; ~$15–60+). Tools never paywalled. No public API (the
Swiss Ephemeris is licensed as a code library).

**Features:** Extended Chart Selection with dozens of methods — natal,
transit bi-wheels, secondary progressions, solar arc, solar/lunar returns
(incl. kinetic), composite (midpoint), Davison, synastry, harmonics, local
space, horizon/azimuth, Gauquelin sectors, draconic; tropical/sidereal with a
long ayanamsa list; ~15–20 house systems; full planets + Chiron + main
asteroids + Nessus/Eros/etc + mean/true/osculating Lilith + Uranian
hypotheticals + ANY of 20,000+ named asteroids by catalog number; fixed
stars; selectable aspect sets with global orb scaling; the famous 9,000-year
ephemeris (5400 BC–5399 AD) free as PDFs; AstroClick Travel (free interactive
astrocartography); AstroClick Portrait (clickable natal chart); Astro-Databank
wiki of 60,000+ Rodden-rated charts; excellent historical-timezone atlas;
high-res printable chart PDFs.

**Design:** the weak flank. Sprawling multi-level directory IA; CGI-era URLs;
the Extended Chart Selection is a dense, intimidating settings form; features
buried in dropdowns ("half the frustration is finding it"); server-generated
raster/PDF wheels with zero interactivity; plain HTML tables; partial
responsive retrofit; registration wall for saving draws complaints.

## 2. astro-seek.com — the free power-tool monster

**Positioning:** Czech indie; ~10–12.6M monthly visits, rivaling astro.com.
Every calculation, 100% free, no paywall; Reddit's default recommendation.

**Model:** entirely free, ad-supported. Free profile saves charts. No premium
tier — traffic-scale advertising only.

**Features (widest list anywhere):** natal; transit; synastry; composite;
Davison; secondary/tertiary/minor progressions; progressed synastry; solar
arc; PRIMARY DIRECTIONS (multiple keys — essentially unavailable elsewhere
online); solar return with relocation, lunar return, Saturn return; draconic;
harmonics; persona charts; relocation. Traditional module: whole-sign with
essential dignities, sect, Arabic parts, annual profections, firdaria,
planetary hours, horary calculator. Sidereal with many ayanamsas, N/S Indian
styles, nakshatra calculator. ELECTIONAL SEARCH over a date range. Astro-
cartography + local space. Search engines: aspect/date search, retrograde and
ingress calendars, eclipse catalogs centuries deep, VoC Moon calendar, Moon
phases, fixed stars, midpoints, declinations/OOB, Sabian symbols, dominants,
pattern detection, rectification helper. Full ephemeris incl. DE431 long
range (13,201 BC–17,191 AD). ~10–12 house systems, custom orbs/aspect sets,
extensive wheel-graphics customization (incl. "Solar Fire style" skin).
Celebrity DB browsable by placement. CHART STATE IN THE URL — shareable
without an account.

**Design:** utilitarian 2010-era: white background, blue links, dense link
lists, small type, SEO footer link-farms, ads between form and results;
server-rendered PNG wheels; every tool its own long page (needed a dedicated
"tools search" page); cramped mobile. "Function over form… assumes you
already know astrology."

## 3. astro-charts.com — the design-led minimalist

**Positioning:** indie; "The quiet study of your sky"; beautiful simple free
charts — the anti-astro.com. Design-conscious beginners; TikTok-recommended.

**Model:** free charts, no account for basics; free account saves charts;
paid ~80-page personalized natal guide. Minimal ads.

**Features:** natal, synastry, composite, transit. Signature: interactive SVG
wheel (hover/tap aspect lines and planets to highlight + detail), automatic
pattern-detection badges (stellium, grand trine, T-square, yod, kite, grand
cross, mystic rectangle), big-three/big-six chips, clean aspect tables,
shareable chart URLs, downloadable images, celebrity pages (SEO). Settings
deliberately thin: few house systems, tropical only, planets +
nodes/Chiron/Lilith.

**Design:** best-looking chart renderer in the category — dark quiet
aesthetic, generous whitespace, one clean form, instant SVG, responsive,
fast. Flat IA: four chart types + saved charts. Pattern badges = the
most-copied UI idea in the space.

**Weaknesses:** shallow — no progressions, returns, Davison, directions,
harmonics, ephemeris, calendars, electional; power users outgrow it in a
week.

## 4. cafeastrology.com — SEO colossus, 2003-era tools

**Positioning:** Annie Heese's content empire; ~4.5–6M visits, ~44% organic.
Mass-market beginners from search. Tools on astro.cafeastrology.com.

**Model:** free chart reports (heavy ads); paid written reports ($5–15); no
subscription; simple free login stores birth data.

**Features:** free natal report (wheel image + positions + aspects + house
table + text); HOUSE SYSTEMS AS SEPARATE PAGES (distinct calculators for
Placidus, Whole Sign, Equal, Koch, Porphyry, Alcabitius, Campanus,
Regiomontanus, Morinus, Topocentric, Vehlow) plus a genuinely useful "Compare
House Systems Report" tabling placements across 12 systems; sidereal variant;
unknown-birth-time variant; synastry reports; romantic compatibility ratings;
transit/forecast reports; reference tables (current positions, retrograde
tables, eclipse lists, VoC tables + monthly PDF calendars). No
astrocartography, returns, directions, harmonics, electional, API.

**Design:** among the most dated: early-2000s templates, narrow fixed-width,
beige/lavender, tiny fonts, dropdown date entry, static GIF/PNG wheels, high
ad density, mobile = squeezed desktop. IA: one giant flat link directory
(~40 links).

## 5. astrology.com — modern media brand, shallow tools

**Positioning:** Ingenio-owned (with Horoscope.com, Keen psychics); ~6M
visits; polished mainstream lifestyle; casual mobile horoscope-first
audience.

**Model:** free basics; ~45 à-la-carte reports $6.95–$24.95; Astrology+
subscription $4.99/mo / $49.99/yr; heavy Keen psychic cross-sell.

**Features:** clean birth-chart calculator → simple wheel + placement blurbs;
compatibility score/text (not real synastry); tarot draws; side calculators.
NO settings (one house system, tropical), no asteroids, no dated transits, no
ephemeris, no returns/progressions, no tables, no export, no API.

**Design:** most modern-feeling mass site: 2019+ redesign, pastel
illustration, card IA (Horoscopes/Tarot/Birth Chart/Compatibility/Shop), big
type, responsive, location autocomplete. Wheel pretty but static and
information-thin.

**Weaknesses:** near-zero tool depth; aggressive monetization/upsell
interstitials; chart is a lead magnet, not a product.

## 6. astrotheme.com — celebrity-chart research engine

**Positioning:** French, since ~2002, FR/EN; THE celebrity horoscope database
(~78,000 interactive charts, ~40,000 with known birth time).

**Model:** free charts + celebrity DB + registered daily horoscope; paid
computed reports (€10–30).

**Features:** free natal with dominant calculations (planetary/sign/house —
a house specialty), several house systems, transits/forecasts, synastry. The
unique power tools: search 78k charts by up to 3 simultaneous aspects with
adjustable orbs, by up to 4 criteria (planet in sign/house, degree ranges),
by profession/country/dominant. Real-time "charts being viewed" feed.

**Design:** dated French-portal: dense serif text blocks, blue/gold, long
pages, image wheels, 2005 database-frontend search forms, frequent
registration prompts, partial responsive.

## 7. astrostyle.com (AstroTwins) — media brand, toy calculators

**Model:** free calculators as email-capture; revenue from books, courses,
retreats, readings.

**Features:** "Cosmic Calculators" hub of single-purpose lookups (rising,
Moon, Saturn, nodes, Venus/Mars, composite, solar return with "where to spend
your birthday"), free natal with mini-reading. No settings, one house system,
no storage.

**Design:** bright WordPress magazine (pinks/purples), pop-ups, responsive.
The instructive IA idea: ONE CALCULATOR PER QUESTION ("What's my rising
sign?") — matches search intent, ranks phenomenally.

## 8. costarastrology.com (web) — brutalist funnel

Free natal chart page in the signature terse voice; no settings, no synastry
on web, no tables/export; the site is a download funnel. Distinctive B/W
brutalism, thin serif + monospace, star-map graphics. Web user = app lead.

## 9. chani.com (web) — polished whole-sign on-ramp

One free birth chart generator: clean form → whole-sign wheel + placements
(nodes, MC/IC/DSC, Chiron, Lilith) each with a plain-language role summary
("Your Rising Sign — how you meet the world"). No options, no other chart
types, no tables/export. Arguably the best visual + copy design in astrology:
warm gradients, soft shapes, superb type, accessible language. All depth
behind the app subscription.

## 10. alabe.com (Astrolabe) — the fossil with a famous free chart

Solar Fire's publisher; `/freechart/` ASP form → wheel image + short
computed reading; no options, no storage; funnels to Solar Fire (~$360),
reports, ACS Atlas. Genuinely mid-1990s design. Its huge "free birth chart"
search traffic is poorly served.

## 11. prokerala.com — Indian portal + the API play

Free Vedic tools (kundli N/S Indian styles, guna milan + 10-porutham
matching, nakshatra, doshas, dasha periods, panchang, muhurat/choghadiya) +
a broader-than-expected Western set (natal, transit, progression, solar
return, synastry, composite). Standout: a commercial REST Astrology API
(api.prokerala.com; free tier + paid) + WordPress plugin — none of the
Western majors sell an API at all. Functional dense portal design,
ad-interleaved.

## 12. Others

- **astrosage.com** — Vedic giant (~12M users, ~80% of India's online kundli):
  free kundli, KP, Lal Kitab, Varshphal, matching; Dhruv Astro Software (paid
  CLOUD pro suite with mobile↔web sync — a model no Western site has);
  astrologer marketplace. Dense, ad-heavy, dated.
- **astromatrix.org** — free web+app, deep free chart: 23+ bodies, pattern
  detection, declinations, Sabian symbols, free synastry/transit reports.
  Mid-tier design.
- **astrograph.com** — TimePassages vendor; free web chart, funnels to apps.
- **astrolibrary.org** — simple free calculator + long auto reading; SEO.
- **horoscope.com / tarot.com** — Ingenio siblings; biggest traffic (~12M),
  same shallow calculator pattern.
- **AI entrants** (my-zodiac-ai, upastrology, asknova, selfgazer…) — modern
  UI + AI interpretation + subscription; calculation even shallower than
  astro-charts. They validate demand for modern UX; none threaten the power
  tier.

### (b) Power features trapped behind 1996–2010 UIs

Primary directions, solar arc, tertiary/minor progressions; Davison;
harmonics/draconic; the traditional toolkit (dignities, sect, lots,
profections, firdaria, horary); electional scanning; astrocartography;
house-system/ayanamsa switching; deep ephemerides, eclipse catalogs, VoC/
retrograde/ingress calendars, aspect-date search; asteroids/fixed stars/
Uranians/declinations; queryable celebrity DBs; rectification helpers,
midpoints, dominants. Every one absent from every modern-looking product.

**The market is a barbell** — ugly-but-omnipotent (astro.com, astro-seek,
cafeastrology, astrotheme) vs beautiful-but-hollow (astro-charts,
astrology.com, Co-Star web, CHANI web). Ten-million-user traffic on each side
proves both demands; nobody serves both.

### (c) IA/layout patterns that work

- Chart state in the URL (astro-seek) — the single best pattern in the
  category.
- Interactive SVG wheel with hover-highlight + tap-detail (astro-charts).
- Pattern detection surfaced as badges (astro-charts, astromatrix).
- One-intent-one-page SEO calculators that deep-link into one engine with
  presets (astrostyle, cafeastrology).
- A single dense hub page listing every tool (astro.com, astro-seek).
- Progressive disclosure: simple form + persistent "advanced settings"
  drawer.
- Persistent person/chart switcher carried across every tool (astro.com's
  "Horoscope for:").
- Comparison tables as product (cafeastrology's compare-house-systems).
- Celebrity pages as SEO + worked examples.
- Plain-language labels beside jargon (CHANI).

### (d) How a new 100% free modern site wins

1. One engine, one form, every chart type — a single workspace with a type
   switcher and persistent people library.
2. Client-side computation — instant recalculation, live date-scrubbing with
   the wheel animating (category-first "wow"; incumbents reload pages).
3. Interactive SVG everywhere; pattern badges; aspectarian cross-highlighting.
4. No login walls; state in the URL; export everything free (SVG/PNG/PDF/CSV).
5. Settings as a persistent profile with presets (Modern / Traditional /
   Vedic / Uranian), global with per-chart overrides.
6. Own the calendar/almanac layer with modern UI + ICS export (nobody offers
   calendar export).
7. Electional scanner with a green/red timeline UI (only astro-seek has the
   math; its UI is a form-and-table).
8. Astrocartography as a first-class interactive map.
9. Research database done right (Rodden-rated data, modern query builder,
   queries across your own saved charts).
10. Programmatic SEO pages resolving into the single engine with presets.
11. Free documented API (only prokerala sells one).
12. Trust levers: historical-timezone atlas accuracy, methodology
    transparency, light/dark themes, accessible tables, restrained ads.
