# Competitive research: professional & power-user astrology software (2025–2026)

Agent-gathered web research, 2026-08-15. Establishes the feature ceiling
serious users expect. Interpretation content excluded.

---

## 1. Desktop professional suites

### Solar Fire 9 (Astrolabe, Windows) — the industry reference
- **Price:** $306–360 one-time; Windows-only (Mac via Parallels — persistent
  pain point).
- **Timing:** secondary progressions (multiple rates), solar arc + ~30 arc
  directions, primary directions (Placidus/Regiomontanus, mundane and
  zodiacal, Van Dam), tertiary/minor progressions, returns of every kind
  (solar, lunar, demi/quarti, planetary, phase, kinetic), profections,
  firdaria (with variants), interactive zodiacal releasing table (L1–L4,
  peaks, loosing of the bond), eclipses/ingresses/lunations, user-defined
  progressed points.
- **Electional/horary:** dedicated electional SEARCH module (search a range
  for chart conditions), horary mode with strictures, planetary hours, VoC
  listings.
- **Predictive graphing:** Time Map (multi-technique horizontal timeline of
  hit bars), graphic ephemeris (45°/90°/360°, transits + progressions over
  natal lines), dynamic hit lists, chart animation with rectify assist.
- **Maps:** astro-locality maps (angle lines + parans), local space,
  relocated charts; ACS Atlas embedded.
- **Research:** chart DB with criteria search ("all charts with Mars in Aries
  in 10th"), import/export, categories.
- **Traditional:** sect, dignities table with almuten scoring, 100+ Arabic
  parts plus user-definable lot formulas, antiscia, 1000+ fixed stars with
  parans, planetary hours, temperament.
- **Vedic:** minimal.
- **Customization:** extreme — per-aspect per-point orb files, ~30 house
  systems, custom asteroid sets, wheel designer, custom "Pages" (dashboard
  layouts mixing wheels + grids + tables), custom aspect sets.
- **UI:** single/bi/tri/quad wheels, synastry grids, aspectarians everywhere,
  midpoint trees; dense WinForms-era UI, powerful but dated.

### Astro Gold (macOS/iOS/Android)
~$99 mobile, ~$250–290 macOS. Solar Fire's mobile/Mac sibling: progressions,
solar arc + user rates, returns, firdaria/profections/ZR as tabular "Astro
Sheets", time lists; dignities/sect/almutens/lots/antiscia sheets; astro-
locality on macOS; Solar Fire-compatible chart files; ~30 house systems. No
primary directions module, no electional search. Best-designed native pro
mobile app.

### TimePassages Pro/Advanced (Win/Mac/mobile)
$79–279 (+bundles). Modern-psychological toolkit: transits, secondary
progressions, solar arc, solar/lunar returns, rectification assist,
astrocartography (Advanced). NO time-lords, no primaries, no electional.
Polished consumer-grade UI; interpretation-on-click is the differentiator.

### iPhemeris (iOS/macOS)
~$29.99 iOS / ~$99 macOS + All Access subscription (fixed stars, extended
ephemeris 4700 BC–2995 AD). Ephemeris-first: book-style monthly pages,
graphic ephemeris WITH natal overlay (rare on mobile), astro-calendar
against any stored chart, Sky Now, VoC; transits, progressions, solar arc,
returns, relocation; astrocartography (premium); 800+ fixed stars;
declinations. No time-lords, dignities suite, or Vedic.

### Kepler 9 / Sirius 4.1 (Cosmic Patterns, Windows)
Kepler ~$300, Sirius ~$450–550. Everything: progressions, solar arc, primary
directions, all returns, time-lords (Sirius Hellenistic module), cosmobiology
dials, harmonic ages. Sirius has genuine electional search + horary. Hallmark
visualization: stacked "forecast graphs" (transit intensity curves), graphic
ephemeris, financial overlays. THE research leader: AstroSignature scoring
with significance stats, built-in Gauquelin + famous-chart DBs (tens of
thousands), criteria search. Sirius includes real Vedic (vargas, dashas,
nakshatras, some ashtakavarga) — the only mainstream Western suite that does.
Dense dated UI.

## 2. Free desktop power tools

### Planetdance (Windows, free)
Astonishing breadth: profections, ZR, firdaria, primary directions,
progressions, returns, lots, antiscia, fixed stars, harmonics, ingresses,
eclipses, planetary hours, almutens, horary module, electional aids,
synastry/composite, midpoints, declinations; Vedic module (vargas,
vimshottari). Chart DB with criteria search; Astrobasic scripting language
with a community module "app store". Old-school UI.

### Astrolog 7.80 (free, open source)
Every coordinate system (geo/helio/sidereal/3D), dozens of house systems,
transit graphs + hit lists, returns, local space + astrocartography maps,
fixed stars, asteroids, Uranians, 3D globe renderings, scripting. No
time-lords. Famously idiosyncratic keyboard UI.

### Morinus (free, open source; "Traditional Morinus" build)
The free reference for primary directions (multiple keys, mundane/zodiacal,
converse); distributions through bounds, firdaria, profections, solar
revolutions, progressions, 800+ fixed stars, lots, dodekatemoria, antiscia,
almutens (incl. almuten figuris), temperament, electional + horary tools.
Spartan single-wheel UI; development dormant.

## 3. Specialist traditional & Vedic

### Delphic Oracle WL (Windows, ~$199.50)
"Gold standard of Traditional Astrology programs" (Hank Friedman); Project
Hindsight lineage. The deepest time-lord implementation anywhere: ZR with
peaks/angular triads/loosing of the bond, decennials, 129-year system,
circumambulations/primary directions through bounds, profection variants,
firdaria, planetary years; sect, dignities, almutens, Valens' full lot set +
custom, antiscia, temperament, length-of-life techniques; medieval solar
returns with profection integration. Gantt-like time-lord period stacking.
Windows-classic UI, unmatched domain depth.

### Jagannatha Hora 8.x (Windows, free) — the free Vedic standard
20+ vargas (to D-150), every major dasha system (dozens, 5 sub-levels), full
ashtakavarga (BAV/SAV, transit scoring), nakshatras, shadbala, yogas, tajaka
annual charts, muhurta module, panchanga, KP support, extreme precision
options. Dense tabbed UI of Indian-style square charts + tables.

### Parashara's Light 9 (Windows; ~$60 personal / $240–310 pro)
5000+ calculations, all vargas, major dashas, ashtakavarga, shadbala, yogas,
muhurta, varshaphala, KP, rectification tools, 300+ customizable worksheet
layouts. Polished for its market.

## 4. Modern web-based pro tools

### Astro-Charts (free + paid guide)
Modern SVG wheels, pattern detection badges, chart saving. No time-lords, no
progressions depth, no graphic ephemeris, no electional, minimal
customization.

### Honeycomb Collective (honeycomb.co)
Personalized transit ALMANACS (digital from ~$10, printed $27–63): natal +
mundane transits side by side, exact hits in your timezone, moon phases, VoC,
eclipses; tropical/sidereal, 7 house systems, Chiron + 4 asteroids; year-at-
a-glance mundane transit timeline graphics. Proved demand for personalized
transit-timeline products — but static PDF/print, not interactive.

### Archetypal Explorer (subscription, low tens $/mo)
Transit "waveforms" — personal and world transits as intensity curves over
time (orb entry/exit), filterable, zoom from days to centuries, collective
cycle overlays, digests. The one visualization consumer apps most
conspicuously lack. No traditional techniques, returns, wheels, electional.

### Astro-Seek (free)
The benchmark web power tool: ZR, firdaria, profections, primary directions,
graphic ephemeris, returns, harmonics, midpoints, declinations, traditional
view with dignities/sect/lots, ephemerides, electional aids, chart storage.
Weakness: integration and UX (page-reload calculators, no unified timeline),
not coverage.

## 5. API & AI-era services

- **AstrologyAPI.com** (Vedic Rishi): credit-wallet; Western + Vedic
  endpoints (natal, transits, dashas, panchanga, matching, PDF reports). Does
  NOT expose time-lords, primaries, ZR, electional search, or graphic-
  ephemeris data — advanced technique calculation is not commoditized at the
  API layer.
- **FreeAstrologyAPI.com**: 50 req/day free; $15–75/mo; fundamentals only.
- **Infrastructure:** Swiss Ephemeris (AGPL/paid) under nearly everything;
  Kerykeion/flatlib/Immanuel open-source Python for natal + some traditional.
- **AI newcomers:** consensus — LLMs without an ephemeris backend fabricate
  positions; credible tools pair LLM + calculation API. No AI newcomer
  attempts advanced technique calculation or visualization. AI raised the
  interpretation floor, changed nothing at the calculation/visualization
  ceiling.

## 6. Synthesis

### (a) Pro features with NO good free modern-web equivalent
1. **Integrated multi-technique timelines** (Solar Fire Time Map / Sirius
   forecast graphs): transits + progressions + solar arc + time-lord periods
   on one interactive zoomable timeline. THE single largest gap.
2. Interactive graphic ephemeris (45°/90°/360° with natal + progressed
   overlay).
3. Electional search ("find times in the next 60 days where Moon is waxing,
   not VoC, Jupiter angular") — essentially absent from the web.
4. Criteria search across a chart collection; AstroSignature-style scoring.
5. Primary directions with real options (keys, mundane/zodiacal, converse).
6. Unified time-lord stack (ZR + profections + firdaria layered against
   transit triggers, Delphic Oracle-grade).
7. Rectification tooling (animate chart, snap to events).
8. Vedic depth on the modern web (vargas + multi-dasha + ashtakavarga with
   decent UX).
9. Custom dashboard layouts (Solar Fire Pages, Parashara worksheets).

Already commoditized free (not differentiators): natal wheels, synastry/
composite, basic transits, sign/house/aspect tables, basic dasha lists,
isolated traditional calculators, basic API math.

### (b) Pro visualizations consumer apps lack
Aspectarian grids (natal + synastry cross-grids with orb/applying
annotations); bi/tri/quad-wheels with user-chosen rings; transit timeline
graphs (duration bars + intensity waveforms); graphic ephemeris; dignity/
almuten score tables; midpoint trees; declination graphs; 90° dials;
speculum tables; return + profection composite views.

### (c) Minimum bar to be taken seriously by intermediate/advanced users
1. Swiss-Ephemeris-grade accuracy, visible arc-seconds, true/mean node
   choice, stated ayanamsa.
2. House systems: Placidus, Whole Sign, Koch, Regiomontanus, Porphyry,
   Equal, Campanus minimum.
3. Full orb control: per-aspect AND per-point, savable profiles,
   applying/separating flags.
4. Custom point sets: Chiron, main asteroids, nodes, Lilith variants,
   vertex; option of arbitrary asteroids/fixed stars.
5. Chart database with fast entry (atlas + timezone history — silent
   dealbreaker), folders/tags, import/export.
6. Bi-wheel minimum, tri-wheel to be credible, with ring choice; synastry
   grid; natal aspectarian.
7. The non-negotiable predictive quartet: transits + secondary progressions
   + solar arc + solar/lunar returns, with hit lists and relocation.
8. A time visualization — duration-bar timelines minimum; graphic ephemeris
   earns real respect.
9. Traditional basics (2025 baseline, post-Hellenistic-revival): sect,
   dignities table, annual profections, Fortune/Spirit, whole-sign done
   correctly; ZR and firdaria now expected by the advanced-intermediate
   cohort.
10. Precise event times in the user's timezone (eclipses, stations,
    ingresses, VoC) — pros check these against references.
11. Clean wheel PDF/PNG export.

Nice-to-have tier that flips pros to switching: electional search, primary
directions, criteria search across saved charts, astrocartography with
parans, custom dashboards, API/scripting.

**Net read:** the ceiling is Solar Fire/Sirius (breadth + research), Delphic
Oracle (traditional depth), JHora (Vedic depth) — all Windows desktop, all
dated, none web-native. The web has beautiful wheels (Astro-Charts), one
great timeline viz (Archetypal Explorer), static almanacs (Honeycomb), and
encyclopedic-but-clunky calculators (Astro-Seek). Nobody has shipped the
synthesis: web-native, desktop-grade timing techniques, integrated
interactive timeline/graphic ephemeris, real multi-wheels and aspectarians,
electional and collection search.
